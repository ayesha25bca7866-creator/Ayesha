# Python Expense Tracker 💰

A simple expense tracking application built using Python and SQLite.

## Features
- Add expenses
- View all expenses
- Calculate total spending
- Filter expenses by category
- Delete expenses
- Store data in an SQLite database

## Technologies Used
- Python
- SQLite

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the command:

   python main.py

## Database
The expenses.db file is created automatically when the program runs.
